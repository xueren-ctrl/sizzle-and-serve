Sizzle & Serve — a one-chef cooking rush: take orders, grill patties, chop veg, build dishes on the plate and serve before patience runs out. Three-minute shifts, tips for fast service, and a burn timer that punishes slow hands.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or open `game/index.html` directly in a desktop browser — the game plays offline, keyboard and mouse, no build step, no network.
